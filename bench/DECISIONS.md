# DECISIONS - 判决、已证伪、开关、未结项

与 `RESULTS.md` 冲突处以 `RESULTS.md` 的数字为准；本文件只回答"这意味着什么、还能不能做"。
本文件只记录 qwen36 运行时（design）的判决。新判决按编号追加，不改写已生效的条目。

## 1. 可达性判决（2026-10-24，基于 M0 实测）

| 问题 | 边界 | 判决 |
|---|---|---|
| 单流 TG 130 | 稠密每 token 2.17 GB，217 GB/s -> 10 ms -> 单步 <= 100 tok/s | **单步不可达**，必须把一次前向摊到 k 个 token |
| 完整词表 MTP 能否达标 | 修正投影 102-127（`RESULTS.md` 第 4 节） | **不达标**，只作基线 |
| 受限词表能否达标 | 草稿步约 0.15 ms，只需 E >= 2.1（默认深度）或 2.3（n-max 4） | **有条件可达**，取决于 M1-3 |
| PP 1000 | 6 GFLOP/token -> 需 6 TFLOPS 有效；RDNA2 FP32 峰值约 7.9 TFLOPS，实际 30-50% | **FP32 不可达**，M2 必须走 int8 点积 |
| 显存预算 | 不含 KV 已 7850 MiB，而可用约 7176 MiB | **不成立**，专家缓存要降到 2.5-3.0 GiB（design 5.5） |
| 256K KV | KV 预算待 full-attention 层数确认 | **未定**，出数前不得承诺 256K 驻设备 |
| 静态 top-N 专家驻留 | 25% 覆盖只 46.1% 命中，LRU 97.9% | **已证伪**，必须动态 LRU/SLRU |
| 每 pass 提交与同步开销 | 未测；投影要求 < 1 ms/pass | **未验证**（M1-4） |

三个前提 (a) 局部性跨文本、(b) 受限词表 E、(c) 每 pass 开销 < 1 ms 任一不成立，TG 会落到 110-125，
必须回用户处决定是否下调目标（design 6.5 与第 9 节）。

## 2. 已证伪 / 不要重做

| 方向 | 依据 |
|---|---|
| 单步前向冲 130（加 kernel、调调度、调线程） | 稠密地板 100 tok/s，`RESULTS.md` 第 5 节 |
| 完整词表草稿作为达标路径 | 修正投影 102-127，`RESULTS.md` 第 4 节 |
| 静态 top-N / 整层驻留作为专家缓存策略 | 25% 只 46.1%，`RESULTS.md` 第 2 节 |
| 把 63.8% 当单草稿接受率 | 默认深度约 3，按位置算会高估 E（design 2.4） |
| 只报总 TG、不单列草稿输出头代价 | 会藏掉 2.3 ms/步（design 2.6） |

## 3. 复用判定（运行时对现有 fork 资产）

| 资产 | 复用 | 说明 |
|---|---|---|
| `llama_moe_cache` 的调度与预取 | 否 | design 3.3：依赖旧图，静态驻留不如动态 LRU |
| `llama_context` 图路径作为 decode 主路径 | 否 | design 3.3：每 token 约 4000 节点，MoE 节点在 decode 有缺口 |
| `common/fit.cpp` 的预算式 | 借鉴，不直接复用 | design 5.5 要按 k=8 与专家缓存重算 |

| Vulkan `mul_mat_vec` / `mul_mat_id` 内核 | 复用但需改造 | 要改成批量 k 版本 |
| GGUF 解析、Vulkan 设备初始化、tokenizer | 是 | design 3.3 |

## 5. 未结项（M1 决策门，按阻塞顺序）

1. **N1，M1-1**：10 个 full-attention 层（3、7、11、...、35）与 layer 39 在解码阶段没有 `ffn_moe_*` 回调。
   已排除图复用与 Vulkan topk 融合；CPU 后端下这些层的 `ffn_moe_topk` 是 VIEW。根因未查清。
   影响：U_k 与命中率只覆盖 30/40 层。**不闭环则 M1 决策门不过。**
2. **N2，M1-2**：局部性只在两份技术文本上测过（唯一词比例约 0.4）。对话、代码、多语言未测。
3. **N3，M1-3**：受限词表的 E 未测。它决定 TG 130 是否可达；已测的完整词表投影只有 102-127。
4. **N4，M1-4**：Vulkan 原型的周期时间（含提交与同步）未测，每 pass 开销 < 1 ms 是纯假设。
   这是 design 2.6 全部投影的分母。
5. **N5，M1-5**：带宽（217 / 14.3 / 40 GB/s）是同机历史读数，未在新模型上复测。
6. **N6，design 5.5**：显存预算不成立（不含 KV 7850 MiB 对可用 7176 MiB），专家缓存与计算缓冲的
   最终大小未定稿；KV 一行还是 TBD，需要先确认 full-attention 层数。
7. **N7，design 第 10 节开放问题 3**：是在 `ggml`/`llama.cpp` 之外另建运行时（design 按此写），
   还是在现有 fork 内改造。选后者要重写 design 3.3，并重估"不复用图路径"的理由。
   它是 M2 开工前的用户决策，不阻塞 M1。

处置规则：任一项在第 3 次尝试后仍无进展，按 `AGENTS.md` 第 7 节升级给用户，不得自行下调里程碑阈值。
